Which heats count

How judge totals combine

Example

All heats adds every heat total together. Add all judge totals means two 80-point judge scores become 160 for that heat.

Working example: if a competitor scores Heat 1 = 160, Heat 2 = 145, Heat 3 = 90 and the mode is Best 2 heats, the event total is 305. If the mode is All heats, the event total is 395. If more heats are added later, Best heats still uses the best number chosen here.
